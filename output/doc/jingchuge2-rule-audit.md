## 仍然存在的非问题型差异

这些差异不建议当作缺陷处理：

- DOCX 的若干长句在 JSON 中拆成多条，便于前端排版。
- JSON 对日期做了显式化（例如 `2026 年 3 月 8 日`），比 DOCX 的 `3.8` 更清晰。
- JSON 对部分中文/符号做了规范化空格处理，例如 `×120%`、`+50 分`。
- 个别原文疑似笔误在 JSON 中按语义修正，例如 `收藏品+5个/分` -> `收藏品 +5 分 / 个`。
