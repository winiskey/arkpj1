# 荆楚歌 #2 管控台操作指南

访问地址：`https://jingchuge.fun/admin/login`，输入管理员口令后进入。

---

## 整体流程

```
① 单人计分器录入数据 → ② 成绩审核页锁定 → ③ 战队管理页发布 → ④ 前台排行榜更新
```

---

## 一、赛事总览

登录后默认进入此页，展示：

- **参赛战队数** / **已锁定成绩单数** / **已发布队伍数** / **直播状态**
- 整体录分 → 锁定 → 发布进度条
- 各队成绩排行（基础总分 × 合规系数 = 最终得分）
- 发布阻塞项（红色高亮，必须解决后才能发布）

---

## 二、单人计分器

为单个选手录入比赛快照数据，提交后自动生成成绩单。

**操作步骤：**

1. 选择战队 → 选择选手（主题自动匹配，不可更改）
2. 填写比赛快照数据
3. 点击「计算」预览分数和计分公式
4. 确认无误后点击「提交」

提交成功后，成绩单以 `待审` 状态出现在「成绩审核」页。同一选手重复提交会覆盖旧成绩单。

---

## 三、成绩审核

查看所有成绩单，支持按战队 / 主题 / 状态筛选。

**成绩单状态：**

| 状态 | 说明 | 可执行操作 |
|---|---|---|
| 待审 | 已录入，等待确认 | 锁定 |
| 已锁定 | 审核通过，分数固定 | 退回待审 |
| 已发布 | 随队伍发布，对外公示 | 无 |

**注意：**
- 锁定后分数不可修改，如需更正请先「退回待审」，在计分器重新提交后再锁定
- 已发布的成绩单无法退回

---

## 四、战队管理

管理每支队伍的合规数据，并在条件满足后发布整队成绩。

### 合规数据录入

展开某支队伍后，需填写以下信息：

| 字段 | 说明 |
|---|---|
| 压力位选手 | 必须指定一名队员（其得分额外 ×1.2） |
| 开局源石锭 | 赛前持有数量 |
| 当前源石锭 | 赛后剩余数量（差值为消耗量） |
| 超时分钟数 | 超出规定时间的分钟数 |
| 干员抽取记录 | 每位选手抽取的干员（用于检测重复六星） |
| 教练通话记录 | 每次通话的发起人、目标选手和时长 |

### 系数计算规则

系数从 **1.0** 起算：

- 每超时 20 分钟：**−0.05**
- 每个重复六星干员（跨选手重复）：**−0.1**
- 源石锭消耗超过 200，每超出 1 个：**−0.01**

> 最终得分 = （各选手分数之和 + 压力位加成）× 系数

### 发布条件（全部满足才可发布）

- 已指定压力位选手
- 队伍名单满 4 人
- 教练通话次数 ≤ 3 次
- 每次通话时长 ≤ 3 分钟
- 所有成员成绩单均为「已锁定」状态

点击「发布」后，所有已锁定成绩单升级为「已发布」，队伍总分写入前台排行榜。**发布后不可撤销。**

---

## 五、直播控制

更新直播间信息，保存后实时同步到前台首页的直播入口卡片。

| 字段 | 说明 |
|---|---|
| 状态 | 直播中 / 即将开始 / 已结束 |
| 标题 | 直播间主标题 |
| 副标题 | 补充说明，如「A组 vs B组 半决赛」 |
| 直播链接 | B站直播间地址 |
| 平台标签 | 展示用标签，如「BILIBILI MAIN STAGE」 |
| 首页横幅公告 | 在首页展示的公告文字 |

填写完成后点击「保存并同步到前端」，刷新首页即可预览效果。

## 常见问题

**Q：提交成绩单提示「主题不匹配」？**
成绩单主题必须与选手在队伍配置中的主题一致，检查选手信息是否正确。

**Q：发布按钮不可点？**
查看队伍卡片顶部的「发布阻塞项」列表，逐一解决后按钮自动解锁。

**Q：系数显示异常？**
进入战队管理 → 对应队伍，检查超时分钟数、源石锭消耗和干员重复记录。

**Q：成绩单分数不对？**
分数由后端根据快照数据自动计算。退回待审后，在计分器重新录入并提交即可覆盖。
